## 📋 Description

This project delivers an end-to-end Power BI analysis of sales performance across a chocolate manufacturing company. The dashboard consolidates raw sales records into a clean, interactive reporting layer that allows stakeholders to explore revenue, profitability, and customer behavior at a glance.

The report was built to answer core business questions such as: which products generate the highest revenue, which countries or regions perform best, which salespeople sell the most, how sales trend month over month, which products are most profitable, and what customer insights can be drawn from purchasing patterns. Each visual is designed to move beyond raw numbers and surface decision-ready insights.

Beyond the analysis itself, this project demonstrates practical, job-ready Power BI skills — data cleaning, relational data modeling, DAX measure creation, and interactive dashboard design — making it a strong showcase for Data Analyst and Business Intelligence roles.
